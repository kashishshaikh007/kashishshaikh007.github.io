PROTOCOL-ARENA

A reinforcement-learning gym where LLM agents learn to keep working when the tools and data schemas they rely on change in the middle of a task.

  • 13 tasks and 7 drift classes that fire mid-episode: renamed tools, stricter fields, rate limits, revoked auth and peers going offline.
  • Six weighted reward signals, each exposed for transparency, plus a SQLite knowledge graph that gives the agent memory beyond its context window.
  • Safety layer with honeypot tools and prompt-injection traps, and deterministic replay of every episode.
  • Training notebook: SFT bootstrap, then GRPO with 4-bit LoRA on Qwen2.5-7B.

PhishNet AI

Real-time detection of phishing, malware and defacement URLs, delivered as a Chrome extension that checks every tab you open.

  • EDA and feature engineering on URL datasets to find the strongest phishing signals, then a LightGBM classifier with 98% accuracy.
  • Hybrid engine that combines model probabilities with heuristic checks such as raw-IP hosts and suspicious TLDs.
  • Manifest V3 Chrome extension with in-browser scans under 200 ms and scan history kept locally for privacy.

GhostProof

An auditor that checks whether a user's personal data was really deleted across databases, logs, exports, replicas and backups, instead of trusting a workflow that reports Complete.

  • Classifies 518 deletion requests and resolves current and past identities from an audit log.
  • Reads PDFs, SQL snapshots, JSON and logs locally; a vision model reads only 11 screenshots, cached so reruns cost nothing.
  • Total model cost for the full run: about $0.04.

AutoEIT

Transcribes Spanish learner audio and scores each sentence with the Ortega (2000) meaning-based rubric, for the HumanAI Foundation.

  • Whisper pipeline locked to Spanish that keeps learner disfluencies instead of correcting them, across about 120 utterances.
  • Four-layer scorer: accent-insensitive exact match, multilingual sentence embeddings, word-overlap fallback and zero-score rules.
